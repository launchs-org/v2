## やることは 3 つ

:::steps
1. **データベースを作る**

   いちばん簡単なのは、[テンプレート](templates.md)です。[[+ 追加]] → [[デプロイ]] → **PostgreSQL**、**MariaDB**、**Redis** など。データを入れる[ボリューム](what-is-volume.md)も、いっしょに作られます。

2. **つなぐ先(DNS 名)を調べる**

   データベースのデプロイの [[Service]] タブの **DNS** の欄です。

3. **アプリに渡す**

   アプリの [[起動設定]] の環境変数に、DNS 名、ポート、ユーザー、パスワード、データベース名を入れて、反映します。
:::

## PostgreSQL のテンプレート

| 入力 | 意味 |
|---|---|
| database / user / password | データベース名、ユーザー名、パスワード |
| storage | ボリュームの大きさ(MB) |
| max_connections | 最大の接続数 |
| log_statement | SQL のログを出すか |

接続先のポートは **5432**(MariaDB は 3306、Redis は 6379 が標準です)。

アプリの環境変数の例(PostgreSQL):

```
DATABASE_URL=postgres://ユーザー:パスワード@<ServiceのDNS名>:5432/データベース名
```

## 守ってほしいこと

- **台数は 1 のまま**にします(データを 1 か所にしか置けないため)。
- データは**必ずボリュームに**置きます(テンプレートなら自動)。**ボリュームを消すと、データも消えます**。
- **Ingress で公開しません。**同じプロジェクトの、アプリからだけ使います。ほかのプロジェクトからは、つながりません。
- 環境変数の値は、**画面で見えます**。共有するプロジェクトでは、パスワードの扱いに気をつけてください。
- バックアップは、自動ではありません。大事なデータは、`pg_dump` などで、定期的に取ってください。

:::note tip 中身を見たいとき
テンプレートの **CloudBeaver**(データベースを操作する、Web の画面)を、同じプロジェクトに作ると、ブラウザから見られます。
:::
