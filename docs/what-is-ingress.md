## ひとことで言うと

Ingress は、お店の**入口の看板と、案内係**です。看板が **URL**(例: `https://brave-blue-fox.example.org`)で、案内係が、**「このパスに来た人は、このアプリへ」**という**ルール**です。

- URL は、**自動で払い出されます**(「形容詞-色-動物」の名前)。
- ルールの届け先は、[Service](what-is-service.md) のあるデプロイです。**先に Service でポートを決めます**。
- ルールは、**反映して、はじめて効きます**([下書き → 反映](concepts.md))。
- URL が行き渡るまで、**数分**かかることがあります。

## 公開までの 3 ステップ

:::steps
1. **Service でポートを決める**

2. **Ingress を作る**(URL が付く)

3. **ルールを作って、反映する**
:::

「はじめてのデプロイ」で「外からアクセスできるようにする」を選ぶと、①と②は、自動で済みます。

## 公開したあと

- **アクセスログ**で、誰が、いつ、どこを開いたか、見られます([様子を見る](monitoring.md#access))。
- 公開をやめるには、Ingress を消します(アプリは、そのまま動きます)。

くわしい手順は [インターネットに公開する](publish.md)。
