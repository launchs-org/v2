## 書き出しとは

アクセスログ([様子を見る](monitoring.md#access))は、**24 時間、または 1 つの Ingress あたり 10000 行**までで、古いものから消えます。あとから見返したい、集計したい、というときは、**外に書き出して**おきましょう。

| 送り先 | 向いている人 | 送るタイミング |
|---|---|---|
| **Google Drive** | とにかく手軽に残したい。ボタンを押すだけで、使いたい。 | **1 時間ごと**に、日付ごとのファイルに書き出します。 |
| **webhook** | 自分のサーバーや、ほかのサービスで、すぐに受け取りたい。 | **10 秒〜5 分ごと**(選べます。はじめは 30 秒)に、まとめて送ります。 |

書き出す設定は、**アカウントごとに 10 個まで**です。

:::note warn ログには、アクセスした人の IP と、URL(`?` 以降も含む)が入っています
送り先は、**信頼できる場所**にしてください。URL のパラメータに、パスワードやトークンが入るアプリでは、それも、そのまま書き出されます。
:::

## Google Drive に書き出す

:::steps
**アカウント設定で、Google Drive に接続する**
右上のメニューから[[アカウント設定]]を開き、[[Google Drive]]の[[Google Drive に接続する]]を押します。Google の画面が開くので、使いたいアカウントを選んで、許可します。**1 回だけ**で済みます。

**Ingress の[[アクセスログの転送]]で、[[Google Drive に転送する]]を押す**
書き出したい Ingress を開いて、右のパネルを見ます。押すと、**そこから先のログ**が、書き出されます(押す前のログは、対象外です)。

**[[テスト送信]]で、確かめる**
Drive に、`launchs-connection-test.txt` というファイルができれば、つながっています。消してかまいません。
:::

書き出されたファイルは、Drive の**マイドライブ**に、こう並びます。

```
launchs-access-logs/
  <プロジェクト名>/
    <Ingress のホスト名>_2026-11-26.ndjson
```

- **日本時間の日付ごと**に、ファイルが分かれます。1 行に、ログ 1 件(NDJSON)です。
- 同じ Ingress の、同じ日のログは、**1 つのファイルの末尾に、足されていきます**。ファイルが 50 MB を超えたら、`_part2` のように、次のファイルに続きます。
- **書き出しのタイミングは、1 時間ごと**です。Ingress ごとに、時刻がずれます(同時に集中しないように)。ログがたくさんたまったときは、1 時間を待たずに書き出します。

:::note info 触れるのは、launchs が作ったファイルだけです
launchs の権限は「**このアプリが作ったファイルだけ**」(`drive.file`)です。Drive の、ほかのファイルは、見えませんし、消せません。許可は、Google アカウントの「サードパーティのアクセス」からも、いつでも取り消せます。
:::

### 「再接続が必要です」と出たら

Google の許可を取り消した、長く使わなかった、などで、launchs が Drive に書けなくなると、[[アカウント設定]]の[[Google Drive]]と、Ingress の転送に、**再接続が必要**と出ます。書き込みは、**止まります**。

[[再接続する]]を押して、もう一度、許可してください。**直ると、止まっていた間にたまったログも、書き出されます**(ただし、24 時間か 10000 行を過ぎて、消えたログは、戻りません)。

### 接続を解除する

[[アカウント設定]]の[[Google Drive]]で、[[解除する]]を押します。**Google Drive 宛ての転送は、すべて消えます**。Drive に書き出したファイルは、**残ります**(消すときは、Drive で、消してください)。

## webhook で受け取る

自分のサーバーや、ほかのサービスで、受け取りたいときの方法です。

:::steps
**受け口の URL を用意する**
`https://` で始まる URL です(`http://` や、`localhost`、社内のネットワークの住所は、使えません)。

**Ingress の[[アクセスログの転送]]に、URL を入れて、[[webhook を追加]]を押す**
送る間隔も、選べます(10 秒、30 秒、1 分、5 分)。

**表示された「署名の秘密」を、控える**
**このときだけ**、見られます。受け口で、本物の launchs からの送信かを確かめるのに使います。

**[[テスト送信]]で、確かめる**
受け口に、`{"test": true, ...}` が届けば、成功です。
:::

### 届くもの

`POST` で、次のような JSON が、まとめて届きます(1 回に、最大 1000 件)。

```json
{
  "projectId": "project-…",
  "ingressId": "ingress-…",
  "destinationId": "export-…",
  "logs": [
    {"id": 1234, "ingressId": "ingress-…", "host": "sunny-jade-cat.launchs.org", "time": "2026-11-26T01:42:04.123Z",
     "method": "GET", "url": "/items?sort=desc", "status": 200, "durationMs": 1.5, "clientIp": "203.0.113.9", "bytes": 234}
  ]
}
```

| ヘッダー | 中身 |
|---|---|
| `X-Launchs-Timestamp` | 送った時刻(Unix 秒) |
| `X-Launchs-Signature` | `sha256=` と、HMAC-SHA256(秘密, タイムスタンプ + `.` + 本文)の 16 進数 |
| `X-Launchs-Delivery` | 配送の印(設定の ID と、最後のログの id) |

受け口で、**署名を確かめて**ください(時刻が、5 分以上ずれたものも、断ると、より安全です)。

```js
// Node.js の例
const crypto = require("crypto")
const expected = "sha256=" + crypto.createHmac("sha256", SECRET).update(timestamp + "." + rawBody).digest("hex")
const ok = crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature))
```

- **2xx を返せば、成功**です。それ以外や、10 秒以内に返事がないときは、**失敗**として、あとで、同じログを**もう一度**送ります(間隔を、倍々に延ばして、最大 1 時間)。
- そのため、**同じログが、2 回届くことがあります**。ログの `id` で、重複を取り除いてください。
- 直ったら、たまっていた分が、**まとめて**届きます。

## 止める・消す

Ingress の[[アクセスログの転送]]に、各行の[[停止する]]([[再開する]]で戻る)と、[[削除]]があります。**止めている間のログは、再開しても、送られません**(止める前に送った位置から、続きが送られますが、そのあいだに 24 時間・10000 行を過ぎて、消えたものは、送れません)。

:::faq 書き出しが「失敗中」になった
行の下に、**理由**が出ています。webhook なら、「受け口が 500 を返しました」「時間内に応答しませんでした」などです。**受け口を直せば、自動で、再開します**。[[テスト送信]]で、すぐに、確かめられます。
:::

:::faq ログが、全部は書き出されていない
次の場合は、全部は残りません。
- **失敗が続いて**、24 時間を過ぎた(または 10000 行を超えた)とき。消えたログは、送れません。
- **1 つの Ingress に、1 秒に約 20 件を超える**アクセスがあるとき。そもそも、アクセスログに、全件は、記録されません(件数の集計には、入ります)。
:::

:::faq 「このサーバーでは、Google Drive は設定されていません」と出る
管理者が、まだ、Google Drive の設定をしていません。webhook は、使えます。管理者に、お問い合わせください。
:::
