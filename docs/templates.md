## テンプレートとは

「WordPress を動かしたい」ときに、アプリ、データの置き場所、公開の入口を、1 つずつ作るのは大変です。**テンプレート**は、それらを、**1 回の操作で、まとめて作ってくれる、ひな形**です。

## 使い方

:::steps
1. **テンプレートを選ぶ**

![「+ デプロイを追加」の選び方。テンプレートか、イメージか](assets/images/wizard-0-choice.png)


   構成図の右上 [[+ 追加]] → [[デプロイ]] で、**テンプレート**を選びます。

2. **版を選ぶ(複数あるとき)**

   テンプレートに新しい版と古い版があるときは、[[版]]の欄で選べます。**特に理由がなければ、いちばん上(最新)のまま**で構いません。版を変えると、入れる項目が変わることがあります。

3. **項目を入れる**

   パスワードや、データの大きさなどを、入れます。**パスワードは、自分で決めて、控えて**ください(入れた値が、そのまま使われます)。

4. **作成する**

   確認して、[[作成]]。必要な部品が、順番に作られます。進み具合は、[[タスク]]タブで、見られます。

5. **公開 URL を開く**

   公開の入口が付くテンプレートは、構成図の Ingress から、URL を開けます。
:::

:::note warn 途中で失敗したとき
失敗したところで**止まり**、**それまでに作れたものは、残ります**。理由は、[[タスク]]タブで、確認できます。残ったものは、手で消すか、直して、作り直してください。
:::

:::note info 上限に注意
テンプレートは、デプロイやボリュームを、いくつか、いっぺんに作ります。[アカウントの上限](account.md)に足りないときは、作成の前に、止められます。
:::
