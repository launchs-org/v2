# launchs 利用ガイド

自分で作った、または、公開されているアプリを、**画面を数回クリックするだけ**で動かして、インターネットに公開できるサービスです。サーバーの難しい知識は、要りません。

> このガイドは、launchs を運営している人(管理者)から、サイトの URL と、(必要なら)招待コードを受け取っている、という前提で書いています。
