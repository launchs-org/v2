## まずは、これで試す

イメージ `nginx:latest` は、簡単なホームページを出すアプリです。ポートは **80** です。

:::steps
1. **プロジェクトを開く**

   プロジェクトの名前を押して、[[構成図]]を開きます(空っぽで OK)。

2. **はじめてのデプロイを始める**

   案内にしたがって、4 ステップを進めます。

3. **① イメージ**

   `nginx:latest` と入れます。

4. **② スペック**

   **small**(あとから変えられません)。

5. **③ 公開**

   「外からアクセスできるようにする」を選び、ポートは **80**。

6. **④ 確認 → 作成する**

   状態が [[ok:active]] になるのを待ちます。

7. **公開 URL を開く**

   Ingress のカードを押して、URL を開きます。数分かかることがあります。
:::

## うまくいかないとき

- 状態が [[bad:failed]] → [[タスク]]で理由を見ます。
- 「見つかりません」→ 数分待ちます。
- 起動しない → イメージ名、ポート番号、大きさを確認([困ったとき](faq.md))。
