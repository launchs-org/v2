## ひとことで言うと

コンテナは、**アプリと、動かすのに必要なものを、ひとまとめに箱詰めしたもの**です。引っ越しの段ボール箱のように、どこへ持っていっても、同じように動きます。

:::words
📦 コンテナイメージ :: 箱詰めされた**ひな形(ファイル)**。`nginx:latest` や `ghcr.io/ユーザー/アプリ:1.0` のような名前で呼びます。「名前:タグ」の、タグは**版**のことです。
🏃 コンテナ(動いているもの) :: イメージを、実際に動かしたもの。launchs では、これを**デプロイ**と呼びます。
🏷 タグ(イメージの版) :: `:1.0`、`:latest` など。同じアプリの、どの版を動かすかを決めます。画面の「タグ」(資源の分類)とは、別のものです。
:::

## 知っておくと安心なこと

- **作り直される前提** — 更新や再起動のたびに、コンテナは**新しく作り直されます**。中に書いたデータは消えるので、残したいものは[ボリューム](what-is-volume.md)に置きます。
- **公開されたイメージだけ** — 誰でも取れるイメージが使えます。パスワードが必要な非公開のイメージは、まだ使えません。
- **大きさ(スペック)** — small / medium / large から選びます。**あとから変えられません**([アプリを動かす](deploy.md#spec))。
- **設定は環境変数で** — 設定の値は、環境変数で渡すのが基本です([アプリを動かす](deploy.md))。

:::note tip 自分のアプリをコンテナにするには
Dockerfile を書くか、Dockerfile なしで作れる **Railpack** を使います。[GitHub との連携](github.md)で、push するだけで、イメージを作る方法を説明しています。
:::
