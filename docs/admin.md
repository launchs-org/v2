## 入り方

:::steps
1. **`/admin` を開く**

   サイトの URL の後ろに `/admin` を付けます。ログイン画面にも、「管理者向けにログインする」リンクがあります。

2. **管理者のアカウントでログイン**

   最初の管理者は、初期設定(bootstrap)のアカウントです。一般のアカウントでは、入れません。
:::

:::note info 権限の反映
管理者にした直後は、最大 15 分ほど、入れないことがあります。いったんログインし直してください。
:::

## タブの一覧

| タブ | できること |
|---|---|
| 概要 | ユーザー数、デプロイ数などの全体の様子。 |
| ユーザー | 一覧(ロック中の表示つき)、管理者の付け外し、BAN、**パスワードのリセット**。 |
| 招待 | 招待コードの発行(1 回だけ使える)、一覧、取り消し。 |
| ログイン履歴 | 全員のログインの成功・失敗の記録。 |
| デプロイ | 全員のデプロイの一覧と状態。 |
| アクセスログ | 全体のアクセスの記録。 |
| クォータ | 全体の初期値の変更と、ユーザーごとの上限の変更。 |
| セキュリティ | 不審な IP の確認、IP のブロック、管理操作の監査ログ。 |
| 設定 | システムの設定を見る(読むだけ。変更は、デプロイの設定で)。 |

開いているタブは、URL の `#` 以降に入ります。再読み込みしても、同じタブに戻ります。

## よくある操作

### パスワードをリセットする

:::steps
1. **ユーザーのタブで、[[パスワードのリセット]]**

   **一時パスワード**が、**1 回だけ**画面に出ます。本人に、安全な方法で伝えます。

2. **本人が、ログインする**

   最初に、**新しいパスワードを決める画面**が出ます。すべての端末のログインは、外れます。
:::

:::note warn 管理者のパスワードは、画面からはリセットできません
事故を防ぐためです。サーバーで、`task admin:reset-password`(コマンド)を使います。
:::

### IP をブロックする

セキュリティのタブで、不審な IP(失敗が多い IP)を確認して、**ブロック**します。

- ブロックされるのは、**ログインとサインアップだけ**です(公開しているアプリには、効きません)。
- **自分の IP は、ブロックできません。**

### クォータを変える

全体の初期値は[[クォータ]]のタブで変えます。ユーザーごとの上限は、ユーザーを選んで変えます。

## 守ること

- 管理操作は、**監査ログ**に残ります(消せません)。
- ログインは、**5 回失敗すると 15 分ロック**されます。ユーザーの一覧に、ロック中が出ます。
- 管理者の数は、必要な人だけに。
