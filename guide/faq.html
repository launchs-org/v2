困ったとき(FAQ)

よくある困りごとと、直し方です。気になる質問を、押して開いてください。

困ったら、この順番で

① タスクで、失敗の理由を見る → ② イベントで、起動しない手がかりを探す → ③ ログで、アプリのメッセージを読む。

アプリが動かない

デプロイが「failed」(失敗)になった / 作ったのに、いつまでも起動しない

作ってから、5 分たっても起動しないと、自動で失敗になって、作ったものは、片づけられます。よくある原因は、次のとおりです。

  • イメージの名前や、タグが違う — 綴りを確認します(nginx:latest のように、名前:タグ)。イベントに「イメージを取得できません」と出ます。
  • 非公開のイメージ — パスワードが必要なイメージは、まだ使えません。
  • 大きさが足りない — アプリが、メモリを使い切って、落ちています。大きなスペックで、作り直します(スペックは、あとから変えられません)。
  • アプリが、すぐ終了している — ログに、エラーが出ていないか、見ます。必須の環境変数が足りない、よくある原因です。
動いていたアプリが、勝手に止まった(台数が 0 になった)

アプリが、落ちては立ち上がる、をくり返す状態が 10 分以上続くと、自動で、台数が 0 になって、止まります(土台に、負担をかけ続けないためです)。

ログとイベントで、落ちる原因を直してから、概要のスケールで、台数を戻してください。

「大きさを変えたい」

スペック(small / medium / large)は、あとから変えられません。新しいスペックで、デプロイを作り直してください。データは、ボリュームに置いてあれば、新しいデプロイにつなぎ直せば、引き継げます。

URL が開けない

公開 URL を開くと、「見つかりません」(404)や、つながらない

次を、上から順に、確認してください。

  1. 数分、待つ — 作った直後は、URL が行き渡るまで、時間がかかります。
  2. Ingress に、ルールがあるか — ルールが空だと、公開されません(インターネットに公開する)。
  3. 「反映」を押したか — 「保存」しただけでは、公開は変わりません。「反映待ち」の帯が出ていないか、見ます。
  4. Service のポートが、アプリの使うポートと、同じか。
  5. アプリの台数が 0 になっていないか(概要タブ)。
  6. アプリが、起動しているか(状態が active か)。
URL を開くと、「502」や「503」と出る

入口(Ingress)までは届いていますが、アプリが、返事をしていません。アプリが、まだ起動中、落ちている、または、ポートが違うことが、多いです。イベントとログを、確認してください。

URL を、自分で決めたい / 独自のドメインを使いたい

URL は、「形容詞-色-動物」の名前が、自動で付きます。自分で選ぶことは、できません。独自のドメインへの対応は、管理者に、相談してください。

操作できない・反映されない

「保存」したのに、変わらない

launchs では、保存は下書きです。反映を押すまで、動いているアプリは、変わりません(しくみと言葉)。「未反映の変更があります」の帯を、探してください。

ボタンが押せない / 「反映中」のまま

作っている途中、反映している途中、削除している途中は、終わるまで、ほかの操作ができません。しばらく待ってください。長く止まっているときは、タスクで、状態と、進み具合を見ます。

失敗(failed)になっているときは、直して、もう一度、反映(または削除)を、できます。

「…が上限に達しています」と出て、作れない

作れる数の上限(クォータ)に、達しています。クォータの画面で、使用量を確認して、使っていないものを消すか、管理者に、上限の引き上げを、頼んでください(アカウントと上限)。

ConfigMap(設定ファイル)を直したのに、アプリが、古いままだ

アプリは、決まった「版」を、固定して使っています。編集すると、新しい版ができますが、アプリは、前の版のままです。デプロイの ConfigMap タブで、新しい版に切り替えて、反映してください(データと設定ファイル)。

ボリュームを、小さくしたい

ボリュームは、大きくすることしか、できません。小さくしたいときは、新しい、小さなボリュームを作って、データを移してから、古いボリュームを、消します。

データ

アプリを更新したら、データが消えた

アプリは、更新や再起動のたびに、作り直されます。そのとき、アプリの中に書いたデータは、消えます。残したいデータは、ボリュームに置いて、アプリのマウント先を、データの置き場所に、合わせてください(データと設定ファイル)。

ボリュームや、デプロイを、消してしまった

削除は、元に戻せません。ボリュームの中のデータも、消えます。大事なデータは、削除する前に、アプリの機能で、バックアップしてください。

ログイン・アカウント

ログインできない
  • パスワードを、5 回間違えた → 15 分間、ロックされます。待ってから、もう一度。
  • ユーザー名の綴りを、確認します。
  • それでもだめなら、管理者に、連絡してください(アカウントが、停止されている場合も、あります)。
サインアップできない(「招待コード」を求められる)

招待制のサイトです。管理者に、招待コードを、発行してもらってください。コードは、1 回だけ使えて、期限があります(期限切れ・使用済みは、使えません)。

パスワードを、忘れた

パスワードを、自分で再設定する機能は、まだありません。管理者に、相談してください。

それでも、解決しないとき

管理者に、相談するときは、次を伝えると、早く解決します。

  • 何をしようとしたか(例: 「WordPress のテンプレートで作った」)
  • 何が起きたか(例: 「failed になった」「URL が 404」)
  • タスクに出ている、失敗の理由(コピーして、貼り付け)
  • おおよその時刻
