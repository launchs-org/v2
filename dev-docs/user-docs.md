# 利用者向けドキュメントの書き方(docs/ と tools/docsbuild)

## 2 つのドキュメント

| 場所 | 読む人 | 中身 |
|---|---|---|
| `dev-docs/` | 開発者 | 設計、エンドポイントの仕様、規約、作業の記録 |
| `docs/` | launchs の利用者、管理者 | 使い方(画面の言葉で、やさしく)。**GitHub Pages で公開する** |

`docs/` の Markdown を、`tools/docsbuild`(Go)が、静的なサイト(HTML + CSS)にする。`main` への push で、`.github/workflows/pages.yml` が公開する(リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく)。

## 作る・確かめる

```bash
task docs:build   # docs/ から _site/ を作る(リンク切れ、ナビに無いページ、閉じていないブロックがあると失敗する)
task docs:test    # 生成ツールのテスト
```

`_site/index.html` をブラウザで開けば見られる。CI(`test.yml`)も、同じ生成を通す。

## ファイルの置き方

- `docs/<名前>.md` が 1 ページ(`docs/start.md` → `start.html`)。フォルダは使わない(直下だけ)。
- **全てのページを `docs/nav.yaml` に書く**(サイドバーの見出しと並び。ページの前へ / 次への順番もここ)。無いページは、ビルドが失敗する。
- 見た目は `docs/assets/style.css`(`assets/` の中のファイルは、サイトの直下に写る)。

## ページの先頭(front matter)

```yaml
---
title: "はじめてのガイド"   # 必須。h1 とタブの名前
nav: "はじめてのガイド"     # サイドバーの名前(省略で title)
lead: "ひとこと説明"        # 題の下に出る
crumb: "はじめに"           # パンくずの分類
home: true                  # ホームのページだけ(題と前後の案内を出さない)
---
```

## 書き方

普通の Markdown(表、コード、リンク、`## 見出し {#id}`)に、次の印を足せる。

| 書き方 | 出るもの |
|---|---|
| `[[保存]]` | 画面のボタンや、タブの名前(紫の札) |
| `[[ok:active]]`、`[[run:…]]`、`[[bad:…]]`、`[[warn:…]]`、`[[mut:…]]` | 状態の札 |
| `[ページ](start.md)`、`[見出し](deploy.md#spec)` | ページ同士のリンク(`.md` で書く。ビルドが `.html` にして、切れていないか検査する) |
| `:::note info 題名` … `:::`(`info` / `tip` / `warn`) | 色つきの枠 |
| `:::steps` … `:::`(中に番号つきリスト) | 手順(丸い番号つきのカード) |
| `:::faq 質問の文` … `:::` | 押すと開く、質問と答え |
| `:::words` … `:::`(各行 `言葉 :: 説明`) | 言葉の説明 |
| `:::templates` … `:::` | テンプレートの一覧(`templates/` の定義から自動で作る。手書きしない) |

- ブロックの中に、ブロックを入れるときは、**外側のコロンを少なく、内側を多く**する(`:::steps` の中の `::::note warn …` … `::::`)。リストの中に入れるときは、リストの字下げに合わせる。
- **強調は `**…**` で書く**(日本語の隣でも効く。ビルドが HTML にする)。
- 図(SVG)や、ホームのカードのような凝った部分は、Markdown の中に、HTML を、そのまま書いてよい。
- コードの囲み(```)と、`` `…` `` の中は、印を使わない。

## 内容のルール

- 画面の言葉に合わせて書く。画面や仕様を変えたら、ここも直す(`api.md` は、**エンドポイントを足したら、一覧も直す**)。
- 開発者向けの仕様は `dev-docs/endpoints/`、API の流れと例は `dev-docs/api/`。利用者向けのやさしい説明は、ここ(`docs/`)に書き、仕様を重ねて書かない。
